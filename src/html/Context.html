matstache.Context

Data used to render Mustache templates
A matstache.Context can wrap plain MATLAB data such as structs and can also be subclassed to define reusable structured context data. Subclasses of matstache.Context expose values through their defined properties and methods.

Notes

  • You can pass a struct to any function or method that accepts a matstache.Context object, and MATLAB will automatically convert it.
  • When a tag resolves to a function handle (for structs and wrapped data), Matstache treats it as a lambda.
