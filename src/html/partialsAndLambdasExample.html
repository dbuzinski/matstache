Using Lambdas and Partials

Use Partials to Include Templates Within Templates

We can create a template blog.mustache for our blog that has a list of posts. If we want to reuse the template for a post in other parts of our site, we can store it in another template and use a partial.
% Load a template
template = fileread(fullfile("views", "blog.mustache"));
 
disp(template);
<div> <h1>{{&name}}'s Blog</h1> <h2>Posts:</h2> <div> {{#posts}} {{>post}} {{/posts}} </div> </div>
We can load the template post.mustache to display each post in our list of posts and include that in our blog template using a partial tag.
% Load partials to a struct
partials = struct("post", fileread(fullfile("views", "post.mustache")));
 
disp(partials.post);
<div> <h3>{{title}}</h3> <p>Author: {{&name}}. Created: {{date}}.</p> <p>Summary: {{summary}}</p> </div>
We can load the data containing all posts for a given author. We can retrieve this from a database or another service. For this example, we will load the data from a json file.
% Define a context
jsonData = fileread(fullfile("data", "blog.json"));
context = jsondecode(jsonData);
disp(jsonData);
{ "name": "David", "posts": [ { "title": "Proofs from the Book", "date": "03/30/2026", "summary": "Here are some of my favorite proofs of all time." }, { "title": "The Sensual (Quadratic) Form", "date": "03/23/2026", "summary": "Can you hear the sound of a quadratic? (and why you shouldn't care)", "date": "03/17/2026", "summary": "How are monads used in programming, and how does that relate to their mathematical definitions?" } ] }
Partials are rendered at runtime and inherit the calling context so we can use name from our context in both the blog template and the post template.
% Render the template
out = matstache.render(template, context, partials);
disp(out);

Use Lambdas to Dynamically Modify Templates

Variable lambdas

Section lambdas can be used to modify or replace content within sections.
Function handles with zero inputs can be used as a variable tag. It should return a Mustache template as a string scalar. The lambda will be evaluated, and the returned template will be rendered using the current context.
% Using a lambda, we can transform name to make it bold everywhere
context.rawName = context.name;
context.name = @() "<b>{{rawName}}</b>";
 
% Render the page
out = matstache.render(template, context, partials);
disp(out);
<div> <h1><b>David</b>'s Blog</h1> <h2>Posts:</h2> <div> <div> <h3>Proofs from the Book</h3> <p>Author: <b>David</b>. Created: 03/30/2026.</p> <p>Summary: Here are some of my favorite proofs of all time.</p> </div> <div> <h3>The Sensual (Quadratic) Form</h3> <p>Author: <b>David</b>. Created: 03/23/2026.</p> <p>Summary: Can you hear the sound of a quadratic? Can you feel it?</p> </div> <div> <h3>What is a Monad? (and why you shouldn't care)</h3> <p>Author: <b>David</b>. Created: 03/17/2026.</p> <p>Summary: How are monads used in programming, and how does that relate to their mathematical definitions?</p> </div> </div> </div>

Section lambdas

Section lambdas can be used to modify or replace content within sections.
Function handles with one input can be used as a section tag. It should return a Mustache template as a string scalar. The lambda will be evaluated on the inner content of the section, and the returned template will be rendered using the current context.
% Using a section lambda, we can wrap the section’s inner template (or replace it entirely).
context.posts = @(inner) " Nothing to see here!" + newline;
 
% Render the page
out = matstache.render(template, context, partials);
disp(out);
<div> <h1><b>David</b>'s Blog</h1> <h2>Posts:</h2> <div> Nothing to see here! </div> </div>
