matstache.render

Render a Mustache template

Syntax

out = matstache.render(template, context)
out = matstache.render(template, context, partials)

Inputs

  • template (string scalar): The Mustache template to render
  • context (struct or matstache.Context): Data used to resolve tags
  • partials (struct, optional): A struct whose field names correspond to the names of partial tags and whose values are template strings

Output

  • out (string scalar): The rendered result

See also

matstache.Renderer, matstache.Context
